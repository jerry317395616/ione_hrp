# COD-025 实现审批矩阵解析器

## 任务信息

- 阶段：1-核心闭环
- 模块：HRP核心平台 / HRP Workflow Authorization
- 优先级：P0
- 前置任务：COD-024
- 风险：审批越权、规则歧义、金额与组织上下文篡改、生产迁移

## 验收映射

| 验收项 | 实现 | 自动化证据 |
| --- | --- | --- |
| 审批策略模型 | `HRP Approval Matrix` 与步骤子表 | 元数据、蓝图和字段目录契约 |
| 确定性解析 | 连续阈值、并行会签、唯一最高优先级 | 纯解析与真实单据集成测试 |
| 最小权限 | DocPerm 与组织读写范围同时成立 | 用户、角色、范围和 Guest 测试 |
| 受控 API | `CORE-002`、`CORE-028`、`CORE-029` | HTTP、幂等、乐观锁和只读测试 |
| 审计 | 策略与决策摘要，不记录敏感原值 | 服务审计测试与仓库契约 |
| 迁移与入口 | 三类索引和中文权限工作区 | 重复迁移与 Workspace 映射测试 |

## 实现范围

- 用正式运行模型替换通用设计占位；
- 支持组织、日期、金额、优先级和声明式额外维度；
- 支持角色/用户审批人、并行审批与 All/Any 模式；
- 评估真实目标单据并验证调用方和审批人的数据范围；
- 提供幂等维护接口、只读评估/查询接口和摘要审计。

## 非目标

- 不直接提交、批准或修改业务单据；
- 不替代 Frappe Workflow；
- 不允许 Python、SQL、Server Script 或任意表达式策略；
- 不修改 Frappe、ERPNext 或 Frappe HR 核心源码。
