# 迁移与上线切换清单

1. 冻结目标组织、主数据编码、会计/预算维度与数据责任人。
2. 为每类源数据建立字段映射、清洗规则、重复判断、有效性校验和拒绝原因。
3. 迁移顺序：组织与字典 → 人员/供应商/物资/资产 → 预算/合同/项目期初 → 库存/应收应付/资金期初 → 历史附件和审计证据。
4. 每批数据执行数量、金额、哈希、抽样和业务负责人签字对账。
5. 切换前完成权限模拟、接口并行、关键闭环回归、备份恢复演练和未结业务处置。
6. 切换日停止旧系统写入，执行增量迁移、对账、业务确认、开放新系统；保留只读旧系统。
7. 出现金额不平、关键接口不可用、权限泄漏或严重性能回退时立即回滚。
