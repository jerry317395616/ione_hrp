# ADR-0012 以医院为边界保存不可变的生效日期组织层级版本

## 背景与问题

医院组织会随时间调整。预算、采购、成本、人力和审计不能只引用一棵持续变化的当前树，
否则历史单据在组织调整后会失去原始口径。把院区、科室、护理单元和病区分别建成互相
引用的可变主数据，也无法原子发布一版完整层级。

COD-017 的系统设置已保存默认法人和临时医院标识。COD-018 必须建立正式医院主数据，
并在不丢失旧配置的前提下提供可发布、可回溯的组织层级。COD-019 才负责映射 ERPNext
标准 `Department` 和 `Cost Center`，本任务不能提前耦合标准组织对象。

## 决策驱动因素

- 一个版本必须包含一所医院的完整组织树，不能出现跨医院父子关系。
- 历史版本发布后必须不可变，并能按业务日期确定性解析。
- 新版本必须在数据库锁下取得医院内单调版本号。
- 整棵草稿树必须原子替换，失败时不能留下半棵树。
- 写入必须经过统一领域服务、角色校验、幂等、乐观修订号和脱敏审计。
- 组织节点数量要覆盖大型医院，不能受幂等响应快照节点数限制。
- 不修改 Frappe、ERPNext 或 Frappe HR，也不创建第二个自研 App。

## 备选方案

1. 直接使用 ERPNext `Department` 树：实现快，但历史版本、医院层级类型和原子发布不足。
2. 每种组织类型独立建表并直接互链：字段明确，但版本发布和完整性验证复杂。
3. 只保留一棵当前树并记录变更日志：查询简单，但不能证明历史业务使用的精确结构。
4. 医院主数据、组织版本和统一组织节点三 DocType 聚合，发布版本不可变。

## 决策

采用方案 4。

`HRP Hospital` 是稳定医院边界并关联 ERPNext `Company`。每次创建
`HRP Organization Version` 时，服务锁定医院记录并分配医院内单调
`version_number`。版本以 `effective_from` 表示生效日期；查询某日组织层级时，选择该
医院生效日期不晚于查询日的最新已发布版本。

`HRP Organization Unit` 是版本内的 Nested Set 节点。节点使用严格类型枚举表示医院、
院区、临床科室、行政科室、护理单元、病区、医疗组、成本责任中心、岗位或其他组织。
每版恰好一个 `HOSPITAL` 根节点，父子引用只能位于同一版本，叶节点不能包含下级。

客户端通过结构化节点数组整体替换草稿树。幂等指纹只保存节点数和确定性层级摘要，不保存
节点名称或备注；实际命令最多支持 2000 个节点。发布服务重新读取数据库并校验节点数和
SHA-256 摘要后提交版本。已提交版本和其节点不允许修改、取消或删除。

COD-017 的 `default_hospital` 升级为 `HRP Hospital` Link。旧自由文本值会按法人和旧值
生成确定性 `LEGACY-*` 医院编码，旧文本保留为医院名称，随后更新系统设置引用。

## 后果

业务模块可以保存组织版本和组织节点引用，历史口径不会随当前组织变化。新版本需要复制
完整树，增加少量存储，但换来可审计、可重放和确定的业务日期解析。

组织节点不直接保存 `Department` 或 `Cost Center`。这些标准映射由 COD-019 独立交付，
避免组织版本生命周期与 ERPNext 标准树修改相互污染。

## 验证与退出条件

- 纯契约测试覆盖编码、日期、唯一根、父子完整性、循环、叶节点和 2000 节点上限。
- 锁定 Bench 测试覆盖元数据、旧设置迁移、版本分配、原子替换、修订冲突和不可变发布。
- 真实 HTTP 测试覆盖医院、版本、层级替换、发布、日期查询和缺少幂等键。
- 审计和幂等记录不得包含医院名称、组织名称或备注。
- 重复 migrate 必须幂等，三个隔离站点 `Error Log` 必须为零。

## 迁移与回滚

`bench migrate` 新增三个 DocType 表、两个复合唯一约束，并把系统设置默认医院字段升级为
Link。升级前必须备份数据库。旧医院标识只转换、不删除；回滚到 COD-017 时，旧代码会把
生成的医院编码继续视为受控文本，三个新表和数据保留，不做破坏性删除。

若已发布组织版本，回滚前不得删除版本或节点。后续结构调整必须创建新版本，不能修改
已发布历史。

## 安全与合规

仅 `System Manager`、`HRP System Manager`、`HRP Data Steward` 可调用组织服务。
版本和节点在 Desk 中只读，所有写入使用服务事务。审计只记录修订号、节点数、字段名和
摘要，不记录组织名称、备注、患者、员工或凭据。组织查询在 COD-024 数据范围能力交付前
仅开放给上述管理角色。
